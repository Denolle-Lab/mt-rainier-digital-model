# Mount Rainier seismic network — 3D mockup

Live: https://yaoderek.github.io/rainier-seismic-atlas/

A throwaway visual mockup: the active seismic stations around Mount Rainier on USGS terrain, with
1 m lidar at the summit that loads as you zoom, and the earthquake catalog as toggleable underground
layers (glow cloud, density shells, dots, cut-away, see-through ground).

Navigation: drag to move · Ctrl/⌘-drag or right-drag to rotate · scroll to zoom · arrow keys to glide.

## Data

| Layer | Source | License |
|---|---|---|
| Terrain, 60 × 60 km | USGS 3DEP elevation (≈35–50 m sampling) | public domain |
| Summit, 8.4 × 8.2 km | USGS 3DEP 1 m lidar, tiled at 8 / 4 / 2 / 1 m | public domain |
| Imagery | USGS The National Map, USGSImageryOnly | public domain |
| Stations | EarthScope FDSN station service, active channels on 2026-09-23 | open |
| Earthquakes | USGS ComCat (PNSN), 1980–2026, 15,660 events | public domain |
